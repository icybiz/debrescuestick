The rescue project has a new home.

DebRescueStick is our independent project for a Debian-based USB rescue stick. On the new website, you can prepare a personal image with your public SSH key and download it for a limited time.

About the earlier SystemRescueImage

This section used to offer SystemRescueCd files prepared as directly writable USB images. That version is documented here as a historical project. For current information about SystemRescue, visit its official website.

The original converter remains available as source code: download usb_inst_Mod.sh. This is the historical script, separate from the new image generator.
